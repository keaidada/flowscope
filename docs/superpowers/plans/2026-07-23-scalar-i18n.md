# Scalar API Docs 国际化实现计划

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `/api/docs` 从 Swagger UI 替换为 Scalar UI，并支持 en/zh 语言切换

**Architecture:** 单个文件修改，替换 CDN 源 + 添加语言参数处理。Scalar 内置 `zh-CN` / `en` locale，通过 `localization.locale` 控制 UI 语言。语言选择通过 `?lang=en|zh` query 参数或 `Accept-Language` header 自动检测。

**Tech Stack:** Rust, Axum, Scalar CDN, utoipa

---

## Chunk 1: mod.rs 改造

**Files:**
- Modify: `crates/flowscope-cli/src/server/mod.rs`

- [ ] **Step 1: 添加新 import**

在 `mod.rs` 文件头部的 `use axum::...` 块中，添加：
```rust
use axum::extract::Query;
```

- [ ] **Step 2: 添加 LangQuery 结构体**

在 `OPENAPI_JSON` 常量之后、`openapi_json` 函数之前，添加：
```rust
#[derive(Deserialize)]
struct LangQuery {
    lang: Option<String>,
}
```

- [ ] **Step 3: 替换 scalar_docs handler**

将当前的 `scalar_docs()` 和 `SCALAR_HTML_CN` 替换为以下代码：

```rust
async fn scalar_docs(
    Query(q): Query<LangQuery>,
    headers: HeaderMap,
) -> Html<String> {
    let lang = q.lang.or_else(|| {
        headers
            .get("accept-language")
            .and_then(|v| v.to_str().ok())
            .and_then(|v| v.split(',').next())
            .map(|v| v.split('-').next().unwrap_or(v).to_lowercase())
    });

    let (locale, html_lang, title) = match lang.as_deref() {
        Some("zh") => ("zh-CN", "zh-CN", "FlowScope API 文档"),
        _ => ("en", "en", "FlowScope API Documentation"),
    };

    Html(scalar_html(locale, html_lang, title))
}

fn scalar_html(locale: &str, html_lang: &str, title: &str) -> String {
    format!(r#"<!doctype html>
<html lang="{html_lang}">
<head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>{title}</title>
    <style>
        html {{ box-sizing: border-box; overflow: hidden; }}
        *, *:before, *:after {{ box-sizing: inherit; }}
        body {{ margin: 0; height: 100vh; }}
    </style>
</head>
<body>
    <div id="app"></div>
    <script src="https://cdn.jsdelivr.net/npm/@scalar/api-reference"></script>
    <script>
        Scalar.createApiReference('#app', {{
            url: '/api/openapi.json',
            localization: {{ locale: '{locale}' }},
        }})
    </script>
</body>
</html>"#)
}
```
